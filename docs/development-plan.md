# 開発手順書

## 1. 開発環境とツール
- Xcode：iOSアプリのプロジェクト管理、ビルド、シミュレーター、実機確認
- Claude Code：コード作成、テスト作成、不具合修正
- VS Code：ソースコード・設計書の確認と補助編集
- Git：変更履歴の管理

コード編集は主にClaude Codeで行い、VS Codeは確認・補助編集、Xcodeはビルド・実行・デバッグに使う。同じファイルを複数ツールで同時に編集しない。

## 2. 最初のセットアップ
1. Xcodeで作成済みのプロジェクトを開く。
2. iOS Deployment Target、Swiftバージョン、Bundle Identifier、プロジェクト構成を確認する。
3. 初期状態でビルドし、iPhoneシミュレーターで起動する。
4. プロジェクトのルートにこの設計書一式を配置する。
5. Gitを初期化または既存管理を確認し、Xcode/Swift向け`.gitignore`を用意する。
6. 初期状態のビルド成功を確認した後、最初のコミットを作成する。
7. Claude Codeに`CLAUDE.md`と`docs/`内の設計書を読ませる。
8. Claude Codeにプロジェクトのファイル構成を調査させ、既存構成を壊さない実装計画を提示させる。

Xcodeのバージョンによって利用可能なSDKや設定が異なるため、実際の環境を確認してから実装する。将来App Store公開を行う場合は、その時点のAppleの提出要件を確認して必要なツールへ更新する。

## 3. 段階的な実装計画

### 第0段階：環境確認
- 既存プロジェクトの構成確認
- 初期ビルドとシミュレーター起動
- Git管理
- 設計書の配置
完了条件：初期プロジェクトがビルド・起動し、Gitに記録されている。

### 第1段階：データモデルとレシピ管理
- SwiftDataモデルの実装
- レシピ一覧、登録、編集、削除
- 入力検証、未保存変更確認
- 削除の一括処理
完了条件：関連テストが成功し、ビルドできる。

### 第2段階：週間献立
- 月曜日開始の週管理
- 曜日ごとの複数料理
- 人数設定
- レシピ選択から献立追加
- 前週／翌週移動
完了条件：週・曜日・人数のテストが成功する。

### 第3段階：買い物リスト
- 人数に応じた数量計算
- 材料名の表記ゆれ対応
- 調味料除外
- 単位換算・集約
- 手動削除・購入済み状態
- 再計算失敗時の旧リスト保持
完了条件：計算・集約・状態管理の自動テストが成功する。

### 第4段階：週コピーと設定
- 週の献立コピー
- コピー先置換確認
- 調味料辞書編集
- 状態リセットの整合性
完了条件：コピー・設定・再計算のテストが成功する。

### 第5段階：バックアップ・復元
- バージョン付きJSON書き出し
- ファイル選択UI
- 復元前検証と確認
- 失敗時のデータ保持
完了条件：正常・異常系のバックアップ／復元テストが成功する。

### 第6段階：仕上げと全体テスト
- 空状態、エラー表示、画面遷移
- Dynamic Type、ライト／ダークモード
- シミュレーターと実機テスト
- 全テスト一覧の結果記録
- 不具合修正と回帰テスト
完了条件：定義済みの全テストが成功する。

## 4. 各段階での進め方
1. Claude Codeに対象段階と対象機能を明示する。
2. 実装前に対象ファイル、実装方針、影響範囲を提示させる。
3. 要件や設計の変更が必要な場合は、変更理由と影響を確認して承認する。
4. 小さな範囲で実装する。
5. ビルドと関連テストを実行する。
6. 結果・未対応事項・テスト結果を報告させる。
7. 成功した区切りで差分を確認し、Gitコミットを作成する。

## 5. Git運用
- 作業前に`git status`で未コミット変更を確認する。
- Claude Codeが作業した差分を確認する。
- ビルド・テスト成功後にコミットする。
- ユーザーのレシピ、個人用JSONバックアップ、秘密情報をコミットしない。
- 作業中の変更をユーザーに確認せず破棄しない。

## 6. リリース方針
まず自分用として完成させる。App Store公開はその後に検討し、必要なApple Developer Program登録、提出要件、プライバシー申告、アイコンやストア情報などは公開を決めた段階で確認する。
