# 画面設計書

## 1. 共通方針
- 日本語UI、iPhone縦向き。
- Dynamic Typeで文字を大きくしても操作できるレイアウトとする。
- ライト／ダークモードはシステム設定に追従する。
- 保存や再計算のエラーはユーザーが理解できる日本語で表示し、可能な場合は再試行方法を提示する。
- 入力エラーは可能な限り該当項目の近くに表示する。

## 2. S-01 週間献立
### 表示項目
- 対象週（月曜日〜日曜日の日付）
- 前週へ／翌週へ
- 曜日ごとの料理一覧
- 料理名と人数
- 料理追加、献立から削除
- 買い物リストへ移動
- 他週の献立をコピー
- レシピ未登録時の登録案内

### 操作
- 週移動で月曜日を基準にした週を切り替える。
- 料理追加でレシピ一覧を開き、選択したレシピを当該曜日に追加する。
- 同じ料理を複数回追加できる。
- 人数変更は正の整数のみ許可する。
- 献立から料理を削除しても、レシピ本体は削除しない。
- 週コピーはコピー元の週、コピー先の週を選択する。コピー先に献立がある場合は置き換え確認を表示する。キャンセル時は変更しない。
- 献立に変更があった場合、買い物リストを再計算する。再計算失敗時は旧リストを維持し、エラーを表示する。

### 空状態
- レシピが0件：レシピ登録を案内する。
- レシピはあるが週の献立が0件：料理を追加するよう案内する。

## 3. S-02 レシピ一覧
### 表示項目
- レシピ名
- 必要に応じて基準人数
- レシピ追加ボタン
- レシピ選択、編集、削除操作

### 操作
- レシピ選択は献立への追加フローから利用する。
- 追加・編集はS-03へ遷移する。
- 削除は確認ダイアログを表示する。確認後、レシピ、材料、全週の関連献立登録を削除する。キャンセル時は何も変更しない。
- 削除処理が失敗した場合は全削除を取り消し、エラーを表示する。

## 4. S-03 レシピ登録・編集
### 項目
- レシピ名（必須）
- 基準人数（必須、正の整数）
- 材料行（0件以上）
  - 材料名
  - 数量種別：数値／文字
  - 数値数量または文字数量
  - 単位（数値数量の場合は必須）
  - 表示順
- 参考URL（任意）
- メモ（任意）
- 保存、キャンセル

### 入力ルール
- レシピ名は空白のみ不可。
- 基準人数は正の整数。
- 入力した材料行は材料名必須。
- 数値数量は正の数。単位必須。
- 文字数量は空欄不可（例：少々、適量）。
- URL入力時はURL形式を検証。
- 材料が0件でも保存可能。
- 重複するレシピ名・材料名を許可する。

### 未保存変更
画面を離れる際、未保存の変更があれば確認を表示する。
- 編集を続ける：画面に留まり入力内容を保持。
- 破棄する：未保存変更を捨てて戻る。
- 保存する：検証し、成功時のみ保存して戻る。入力エラーがあれば画面に留まり内容を保持する。

## 5. S-04 買い物リスト
### 表示項目
- 選択週
- 材料名
- 必要量と単位。単位が異なる場合は別数量として表示
- 購入済みチェック
- 項目の手動削除
- 再計算失敗時の古いリスト警告と再試行操作

### 操作・状態
- 買い物リストの表示だけでは再計算しない（再計算が不要な場合）。
- 手動削除はリストからのみ除外し、レシピや献立を変更しない。
- 購入済み状態は週ごとに保存する。
- 献立、人数、レシピ材料、調味料辞書等の変更による再計算成功時は、対象週の手動削除・購入済み状態をリセットする。
- 再計算失敗時は旧リストと状態を保持し、古い可能性を表示する。

## 6. S-05 設定
### 項目
- 調味料辞書の一覧
- 調味料名追加
- 調味料名削除
- バックアップ・復元への導線
- アプリ情報

### 入力ルール
- 調味料名は空欄不可、重複不可。
- 調味料辞書を変更して買い物リストを再計算する場合、再計算成功時に対象週の手動削除・購入済み状態をリセットする。
- 保存に失敗した場合は旧設定を維持する。

## 7. S-06 バックアップ・復元
### バックアップ
- JSON書き出し操作
- 処理中状態
- 成功／失敗メッセージ
- 失敗時の再試行

### 復元
- iOSファイル選択UIでJSONを選ぶ
- ファイル検証結果
- 既存データを置き換える旨の確認
- キャンセル／復元実行
- 成功／失敗メッセージ

不正形式、非対応バージョン、データ整合性エラーの場合は現行データを変更しない。復元キャンセル時も変更しない。

## 8. 画面遷移
- 起動 → S-01
- S-01の料理追加 → S-02（選択後S-01へ戻る）
- S-02の追加／編集 → S-03（保存／キャンセル後S-02へ戻る）
- S-02の削除 → 削除確認ダイアログ
- S-01 → S-04
- S-01 → S-05
- S-05 → S-06
